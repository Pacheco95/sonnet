# Overlay ports

Patched copies of vcpkg ports, picked up through `vcpkg-configuration.json` ahead of the registry ([ADR-0004](../docs/decisions/0004-vcpkg-first.md)). Each directory says what was changed and why, so the patch can be dropped once upstream carries it.

| Port | Change |
|---|---|
| `imgui` | Three changes, copied from the registry at baseline `a1cae005` and bumped to port-version 3. The `sdl3-binding`, `sdl3-renderer-binding` and `sdlgpu3-binding` features depend on `sdl3` with its default features off: the registry port depends on `sdl3` with defaults on, which on Linux re-enables `ibus`, and through it `dbus[systemd]` and `libsystemd`, for every consumer, even one that disabled them at the top level. The `vulkan-binding` feature depends on `vulkan-headers` only and compiles the backend with `IMGUI_IMPL_VULKAN_NO_PROTOTYPES`: the registry port links the `vulkan-loader` port, which put a second loader into the process ahead of the one SDL loads, and vcpkg's loader is built without X11 or Wayland surface support, so the editor could not open a window outside an environment that put the SDK's loader first ([ADR-0006](../docs/decisions/0006-vulkan-object-ownership.md)). `viewport-images-start-undefined.patch` removes the Vulkan backend's creation-time transition of a secondary viewport's swapchain images to `PRESENT_SRC_KHR`, submitted before any image is acquired, which the validation layer reports as `UNASSIGNED-non-acquired-swapchain-image-used` every time such a window is resized; the per-frame barrier now starts from `UNDEFINED`, which every viewport frame allows since it clears or discards the image. |
| `sdl3` | The X11 extensions an editor needs are enabled: XInput2 (relative mouse mode and raw motion), Xcursor, Xfixes, XRandR and XScrnSaver. The registry port turns every X11 extension off so host libraries cannot change SDL's capabilities, which leaves `SDL_SetWindowRelativeMouseMode` unsupported on X11. SDL loads these libraries at run time; the build needs their headers (`libxi-dev`, `libxcursor-dev`, `libxrandr-dev`, `libxss-dev` on Debian and Ubuntu) and stops with a message naming the missing one. The CI runners install them. Copied from the registry at baseline `a1cae005` and bumped one port-version. |
